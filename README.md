Ejercicio 1 — Mi primera JList
Este ejercicio tiene como objetivo que construyas y configures tu primera lista en Swing, comprendiendo cómo mostrar una colección de datos de forma visual y controlada.

Creá una ventana que contenga los siguientes elementos:

Una etiqueta con el texto "Lenguajes de programación"
Una JList con los siguientes elementos: Java, Python, C++, JavaScript, Kotlin, Swift, Go, Rust
La lista debe mostrar 4 elementos visibles sin necesidad de hacer scroll, y debe estar envuelta en un JScrollPane
Un modo de selección que permita seleccionar un único elemento a la vez
Una etiqueta en la parte inferior que inicialmente diga "Ningún elemento seleccionado"
Cuando el usuario seleccione un elemento de la lista, la etiqueta inferior debe actualizarse mostrando el texto "Seleccionaste: [nombre del lenguaje]".

💡 Tip: para responder a los cambios de selección en una JList usá addListSelectionListener. Recordá verificar !e.getValueIsAdjusting() para evitar que el evento se dispare dos veces durante la selección.
